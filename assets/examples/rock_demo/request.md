# Rock Demo

## Goal

Минимальный исполняемый пример layered voxel pipeline: асимметричный серый камень для проверки validator/build/export/review этапов.

## Shape / Silhouette

- не сфера и не яйцо;
- плоское основание;
- несколько крупных угловатых масс;
- заметная асимметрия;
- читаемые ступенчатые сколы.

## Materials

Один матовый серый камень.

## Variants / Stages

Этот пакет содержит только один демонстрационный вариант. Настоящие family/stage assets создаются отдельными пакетами или variant manifests по конкретному Issue.

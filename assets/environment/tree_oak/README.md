# Oak Tree Family (Семейство дубовых деревьев)

Семейство статических воксельных ассетов (`voxel_static`) для **Cube Siege**, заменяющее box-placeholder деревья в основном репозитории `alex123321-maker/Cube-Siege` (Issue #5).

## Варианты и сопоставление со слотами ResourceTree

В основном репозитории `ResourceTree.tree_variation` использует индексы `0..4`:

| Слот | Вариант | Папка | Сетка (X×Y×Z) | Габариты (м) | Воксели | Описание силуэта |
|:---:|---|---|:---:|:---:|:---:|---|
| **0** | **Standard Oak** | `var_0_standard_oak` | 18x28x18 | 2.70 x 4.20 x 2.70 | 1675 | Базовое взрослое дерево; ствол с контрфорсными корнями, видимые сучья, 3 асимметричные массы кроны. |
| **1** | **Tall Oak** | `var_1_tall_oak` | 14x34x14 | 2.10 x 5.10 x 2.10 | 733 | Высокий пирамидальный/колоновидный силуэт (5.1м); трёхъярусная вытянутая крона, читаемые ветви. |
| **2** | **Broad Oak** | `var_2_broad_oak` | 24x24x24 | 3.60 x 3.60 x 3.60 | 2345 | Широкая тяжёлая крона (3.6м размах); массивный ствол, 4 раскидистых сука под кроной. |
| **3** | **Young Oak** | `var_3_young_oak` | 11x16x11 | 1.65 x 2.40 x 1.65 | 239 | Молодое дерево (~2.4м); компактная двухдольная крона, тонкий ствол с развилкой. |
| **4** | **Shrub / Bush Oak** | `var_4_shrub_oak` | 12x9x12 | 1.80 x 1.35 x 1.80 | 290 | Низкий кустарниковый дуб (~1.35м); 3 приземистых холмика листвы с прикорневыми ветвями. |

## Палитра материалов (PBR)

Все варианты используют единую палитру из 3 материалов:
1. `wood_bark` (`W`): тёплая тёмная кора дуба (#42291a), roughness 0.90;
2. `foliage_base` (`D`): глубокая насыщенная лесная листва (#1f5226), roughness 0.85;
3. `foliage_accent` (`L`): тёплый золотисто-зелёный акцент для верхних террас и освещённых шапок (#42852e), roughness 0.80.

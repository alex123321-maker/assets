# References & Visual Contract: Destructible Rock Family

## Visual Contract

В соответствии с `Issue #1` и `docs/STYLE_GUIDE.md` (раздел «Камни»):

1. **Силуэт**:
   - Никаких случайных сфер или яиц;
   - Выраженная блочная (voxel/blocky) геометрия;
   - Несколько крупных читаемых масс вместо мелкого визуального шума;
   - Асимметричные сколы и ступенчатые грани;
   - Плоское и устойчивое прилегание к земле на `y=0`.

2. **Материалы**:
   - Матовый серый камень `stone_gray` (`base_color: [0.38, 0.40, 0.43, 1.0]`, `roughness: 0.92`, `metallic: 0.0`);
   - 1 материал на меш для максимальной производительности (минимальное число draw calls);
   - Отсутствие микротекстурного шума, исчезающего на дистанции изометрической камеры.

3. **Сетка и масштаб**:
   - Размер вокселя: `voxel_size = 0.15` м (15 см) зафиксирован для всех 17 вариантов;
   - Согласованный `bottom_center` origin/pivot у всех вариантов для исключения смещений и скачков меша при runtime swap.

4. **Прогрессия масс**:
   - Монотонное уменьшение массы от Stage 1 к Stage 5 (100% → ~50% → ~25% → ~12% → ~4%).

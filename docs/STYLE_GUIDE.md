# Cube Siege Asset Style Guide

> Это baseline визуального языка, а не закрытый art bible. Конкретный approved reference конкретного ассета имеет приоритет.

## 1. Общий язык

- стилизованное 3D;
- выраженная блочная / voxel readability;
- формы должны хорошо читаться с игровой изометрической камеры;
- силуэт важнее мелкой детализации;
- controlled detail density;
- материалы должны различаться визуально: камень ≠ металл ≠ дерево ≠ ткань;
- избегать фотореалистического микрошумa, который исчезает с игровой дистанции.

## 2. Воксельная геометрия

Воксели — художественный язык, а не требование создавать каждый куб отдельным объектом.

Предпочтительно:
- крупные читаемые массы;
- ступенчатые/кубические края;
- осмысленная асимметрия;
- variation без случайного visual noise;
- consistent voxel density внутри одного семейства ассетов.

## 3. Камни

- не начинать форму со сферы/яйца как основного силуэта;
- flatter ground contact;
- angular broken planes;
- 2–5 крупных масс лучше сотен случайных bumps;
- асимметрия;
- стадии разрушения должны явно уменьшать массу;
- VFX может маскировать swap между независимыми вариантами стадий.

## 4. Деревья

- не строить крону как идеальный шар;
- trunk/major branches должны формировать силуэт до листвы;
- крона состоит из нескольких масс;
- ветки имеют понятное направление и связь со стволом;
- разные виды деревьев различаются прежде всего silhouette, а не только цветом листьев.

## 5. Персонажи/монстры

- readable silhouette;
- пропорции определяются approved reference;
- детали не должны мешать основной массе тела/оружия;
- joints проектируются с учётом анимации;
- важные герои/монстры могут иметь более мелкую voxel density, чем environment props;
- сложное движение важнее буквальной жёсткости каждого voxel cube.

## 6. Материалы

Baseline:
- matte/rough surfaces for stone/wood/cloth;
- metallic response только для реально металлических областей;
- limited palette;
- texture filtering/atlas rules определяются target engine integration;
- не использовать уникальные большие texture maps, если тот же результат даёт маленький atlas/palette.

## 7. Review camera

Всегда проверять:
- orthographic-ish iso view;
- front;
- side;
- top для environment props;
- target gameplay camera, если она доступна.

Ассет, который красив только в close-up render, но плохо читается в игре, не проходит quality bar.
